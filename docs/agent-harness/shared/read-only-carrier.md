# Read-Only Carrier

Read before dispatching research, challenge, or review through the selected
harness adapter.

Use a fresh built-in lane in the current root task. Bind the supplied read-only
role, brief, and evidence boundary. The lane returns evidence or a verdict
while the root retains synthesis, correction, acceptance, and completion.

If a required independent carrier is unavailable, the boundary remains
unaccepted. Do not substitute a write Worker, peer session, or root-local search
for the missing lane. The selected adapter owns native dispatch, identity,
waiting, role mapping, and fresh-context controls.

When the user explicitly requests an optional lane but no native carrier
returns an identity, report the capability gap before continuing root-locally.
Continue only when the requested outcome remains honest and useful without that
lane.
