# Skill Authoring

A skill is a behavioral adapter, not a knowledge base. Its description names
the trigger, owned outcome, and decisive exclusion. Its body keeps only the
domain invariant, decisive method, stop or escalation owner, checkable return,
and a conditional reference handoff. Link the canonical workflow or shared
contract instead of repeating it.

Load one local reference only when a concrete pressure can change the result;
load another only for an independent pressure. Keep existing names and explicit
entry points. Budgets are review heuristics: 50--150 words for session/router
skills, 100--250 for specialists, and 250--500 only for a named non-obvious
method or failure mode.
