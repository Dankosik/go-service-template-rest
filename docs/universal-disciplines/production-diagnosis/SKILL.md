# Production Diagnosis

Use only after the active phase identifies an unknown production cause. Inherit
its authority, artifact, review, proof, output, and completion contract; do not
select incident operations or authorize mitigation here.

Core invariant: quantify the symptom and unaffected complement, localize the
first owning hop, then try to refute a causal mechanism before attributing the
incident or changing the system.

Load one branch:

- symptom contract, impact, perishable evidence, timeline, or hop localization
  -> [localization.md](references/localization.md);
- hypothesis falsification, smallest repair, recovery comparison, or recurrence
  guard -> [causality-and-recovery.md](references/causality-and-recovery.md).
