# Causality And Recovery

Load when a localized hypothesis, repair, recovery claim, or recurrence guard
can change the decision.

State the causal mechanism and its predeclared prediction: if X causes the
symptom through Y, bounded observation Z must appear; name the result that would
refute it. A supported cause explains onset, shape, cohort, and unaffected
complement. A candidate explaining only one dimension remains a contributor or
co-symptom.

Choose the smallest reversible change that removes the mechanism and change one
variable per observation window. Verify by rerunning the original symptom
contract on the same cohort and comparable window, then check adjacent metrics
for displacement. Remove temporary mitigation deliberately; recovery observed
only under mitigation does not prove the repair.

For recurrence, name the broken invariant, leading indicator and alert,
regression falsifier, runbook delta, and gate that should have caught the
change. Each guard needs an owner; documentation without an operational owner is
not closure.
