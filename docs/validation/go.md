# Go Validation

Use the narrowest package test while iterating. Add `make fmt-check`, `make
lint`, and `make test` only when the completion claim spans those separate
surfaces. Repository-wide leaves are not a per-lane or per-sibling default.

Add `make lint-deep`, `make test-race`, or `make test-integration` only when the
changed surface or claim triggers them.

Formatting and linters own mechanical style; tests own behavior.
