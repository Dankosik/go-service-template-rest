# Implementation

Use when one accepted implementation unit is ready and authorized. Own that unit
through code, integration, proof, and one accepted receipt or precise blocker.

## Inputs And Ownership

Read the fixed unit, accepted references, current canonical/generated owners,
real observable path, relevant proof, workspace dirt, and candidate identity
when crossing a boundary. A Lead owns one unit end to end; delegation never
transfers integration or acceptance.

## Method

1. Trace the unit through its real entry point, callers, siblings, owning code,
   tests, wiring, and generated/manual boundary.
2. Locate the earliest causal owner and make the smallest coherent complete
   change. Fix a shared cause once and preserve unrelated work.
3. Delegate only when a bounded separate context reduces work; use the selected
   harness adapter and keep unit ownership with the Lead.
4. Run [Validation Routing](../../validation-routing.md), then apply the
   [Evidence Contract](../shared/evidence-contract.md) to every completion claim.
5. When shared [Review](../shared/review.md) triggers, bind one fixed candidate
   and use its Implementation Review.

Before deployment or costly remote proof, apply [Deployment And Remote-Proof
Preflight](../shared/deployment-proof-preflight.md).

## Output And Acceptance

Return the changed outcome, current claim/proof record, and one accepted result
or exact blocker. For a persisted ledger, apply [Acceptance-Unit
Closure](../shared/acceptance-unit-closure.md) and record the [Task Ledger
V1](../interfaces/task-ledger-v1.md) transition before selecting another unit.
A delegated result or handoff is not acceptance.

## Exit And Reopen

Exit only when the integrated fixed unit satisfies its postcondition,
constraints, mapped proof, and triggered review. When required proof cannot run,
report `implementation complete; verification incomplete` and keep the unit
unaccepted. Reopen the smallest invalid accepted owner with the evidence that
invalidated it; preserve unaffected decisions and resume the same unit. Across a
session boundary use [Handoff](../shared/handoff.md).
