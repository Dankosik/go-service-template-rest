# Research

Use when current or external evidence can change a named task decision. Own
evidence closure and downstream implications, not final behavior or mechanism.

Consume the exact question, affected decision and owner, live alternatives and
falsifiers, authoritative-source boundary, applicable versions and freshness,
and required downstream shape. Label quantities as measured, external limit,
forecast, accepted target, or assumption.

Fix the smallest falsifying evidence and stop condition before searching.
Follow decision-changing claims to current primary authority, test the leading
implication against material counter-evidence and the strongest viable
alternative, and record unavailable surfaces as unknown. Load one matching
branch by default:

- repository/runtime/consumer divergence -> [Current-state
  baseline](research-branches.md#current-state-or-semantic-baseline);
- unfamiliar or current external behavior -> [Current external
  contract](research-branches.md#current-external-contract);
- a live solution family -> [Solution discovery](research-branches.md#solution-discovery-evidence);
- an empirical claim -> [Empirical claim](research-branches.md#empirical-claim-or-probe);
- conflict or freshness -> [Conflict or freshness](research-branches.md#conflict-or-freshness);
- a later input/proof gap -> [Downstream input](research-branches.md#downstream-input-closure);
- an independent read-only question -> [Read-Only
  Delegation](../shared/read-only-delegation.md).

Return a claim-organized synthesis that separates fact, inference, conflict,
assumption, and unknown; each material claim carries a primary locator,
scope/date/limits, counter-evidence disposition, affected decision, and
refresh/reopen condition. Persist only through
[Artifacts](../shared/artifacts.md).

## Review

For an accepted `research only` boundary, apply shared
[Review](../shared/review.md). Missing evidence closure is `FAIL`; only a
bounded later proof risk may be `CONCERNS`.

Ready when the named next owner can act without repeating the search or
re-synthesizing sources. Reopen the smallest evidence or decision owner for a
required gap.
