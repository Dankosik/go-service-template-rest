# Handoff

Use only across a real actor, session, or macro-phase boundary.

Carry the current result, named authoritative sources, movement evidence,
candidate identity when relevant, proof boundary, blocker or next action, and
exact reopen condition. An open decision records its question, owner, affected
decision, and route. Record unresolved fog only with the evidence or decision
that will sharpen it; fog never supports readiness.

Emit a standalone `Next Session Prompt` only after [Phase
Movement](phase-movement.md) permits a different macro phase, then stop. Keep it
to the target phase, ready prior result and evidence, minimal sources, first
action, critical authority boundary, and exact stop/reopen condition. An
incomplete phase, same-phase repair, or context rollover reports resume state
without pretending movement occurred.

Implementation continuation carries only its fixed unit, accepted references,
candidate identity, current proof, attributed dirt, and exact blocker or next
action. It does not release a dependency or create acceptance state.
