# Review Findings

Lead with surviving findings in severity order. Each finding names its anchor,
impact on the accepted outcome, blocker/concern/non-blocking classification,
smallest repair or reopen owner, and current evidence boundary. If none
survives, state the boundary without padding.

Falsify before classifying. A blocker names the observation that would disprove
it and that observation's result. When disproof was not attempted or could not
run, report a concern with that gap rather than a blocker.
