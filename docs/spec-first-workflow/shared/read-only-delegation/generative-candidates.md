# Generative Candidate Lanes

Use only when a hard-to-reverse choice has a real open fork and independent
candidate construction can reduce anchoring.

Give each lane the same accepted drivers, constraints, evidence boundary, and
output interface without exposing another candidate. The root compares only
viable same-level substitutes against the same drivers, synthesizes compatible
elements, and owns the selection. Candidate count is evidence-driven, not a
ceremony.
