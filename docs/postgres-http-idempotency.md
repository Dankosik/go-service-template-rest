# PostgreSQL HTTP idempotency

`HTTP_IDEMPOTENCY=postgres` retains the reusable PostgreSQL-backed idempotency
pack. It requires `DATABASE=postgres` and does not register a protected
operation, make health routes idempotent, or authorize activation.

An adopter supplies the registered operation and every active runtime quantity
through its ordinary typed configuration. Keep the pack disabled until those
deployment-owned values, writer authority, and endpoint recovery contract are
accepted.
