## Go Gopher conductor mascot

The README mascot adapts the Go Gopher character created by
[Renée French](https://go.dev/blog/gopher), licensed under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), using the
`gopher-front` anatomy reference by
[Takuya Ueda](https://github.com/golang-samples/gopher-vector), licensed under
[CC BY 3.0](https://creativecommons.org/licenses/by/3.0/).

The character was adapted into an orchestra conductor and combined with an
original robot orchestra for this project.
