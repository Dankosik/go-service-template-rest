# Durable Messaging V1 Test Design

status: complete

## Proof boundary

Pure parsing, validation, outcome classification, envelope cloning, retry
selection, and lifecycle state transitions use focused package tests. Broker
acceptance, pull limits, durable consumer state, redelivery, reconnect, and
confirmed acknowledgements use a real pinned NATS process; mocks cannot prove
those facts. Process/component tests prove the two composition roots, while the
initializer gate proves physical profile structure. Race and goleak
instrumentation run only scenarios that exercise shared admission, callbacks,
fetch, handlers, and shutdown.

The real-broker fixture uses Testcontainers with
`nats:2.14.3-alpine`, JetStream file storage, bounded contexts, unique stream and
consumer names, and unconditional termination registered immediately after
container acquisition. Messaging subtests are intentionally not parallel: the
loss/reconnect and stopped-server cases own the container lifecycle. A stopped
or unavailable Docker daemon fails when `REQUIRE_DOCKER=1`; a local conditional
skip is never completion evidence.

No mandatory fixture is unavailable. The repository already owns
Testcontainers and OTel SDK dependencies, process helpers, `health.Service`, the
profile initializer harness, race gates, and goleak. Implementation adds only
the selected-package NATS/OTel test fixtures and controlled feature handlers.
