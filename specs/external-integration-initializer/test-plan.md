# Test Design — External Integration Initializer

status: ready

This plan proves the current named-integration contract. Retaining
`OUTBOUND_AUTH=oauth2-client-credentials` keeps only the reusable credential
package; no root OAuth tuple, singleton migration, or `.env` admission exists.
The harness uses disposable local repositories and no provider, credential,
network, deployment, or checkout `.env` input.

## Proof strategy

- `scripts/ci/integration-init-check.sh` owns command grammar, clean-start Git
  transaction, generated/manual containment, no-op/refresh, and named config.
- Generated package tests own config validation, no-I/O construction, auth
  binding, target denial, and close behavior.
- Canonical OpenAPI/Protobuf commands own generated drift.
- Distinct synthetic canaries prove secret and raw-error non-disclosure.
- Every row prints its ID only after its independent oracle passes.

## Deterministic controls

- Every row starts from a fresh committed local fixture with a regular
  `template.lock` and fixed contract.
- Tool execution uses `GOTOOLCHAIN=local`, `GOPROXY=off`, and `GOSUMDB=off`.
- Failures are injected at subprocess boundaries; no scheduler sleeps or live
  endpoints are used.
- Snapshot oracles compare tracked bytes, modes, untracked inventory, and exact
  generated/manual allowlists.
- The expected matrix contains exactly 23 rows.

## Validation ladder

Run against one exact candidate:

1. `make integration-init-check`
2. `go test -vet=off ./internal/config ./internal/infra/httpclient ./internal/infra/grpcclient ./internal/infra/oauth2clientcredentials ./cmd/service/internal/bootstrap`
3. `make openapi-check proto-check`
4. `make project-structure-check ci-change-scope-check`
5. `make template-init-check`
6. `make delivery-quality`
7. `bash scripts/ci/secret-scan.sh change origin/main`
8. `make check`

Unavailable Docker, tools, or readable base refs narrow acceptance; they never
become passing skips. No race or repetition gate is required: the initializer
is process-serialized, and the OAuth package no longer owns a goroutine.
