# Rollout: outbox production closure
status: draft
Affected graph: feature writers + PostgreSQL outbox schema + relay operator path + outbox relay + NATS JetStream, current unclassified/no-adapter state -> receipt-backed sticky-uncertainty state with selected NATS adapter
Irreversible boundary: the last rollback-safe point is before a new writer creates a receipt or a new relay/operator records sticky uncertainty or a non-legacy audit action; after that, stop and roll forward because old code can erase or misclassify evidence.

the generated relay publishes its outbox row through the selected NATS adapter,
