# Test design: outbox production closure

status: ready

Authority: [`spec.md`](spec.md), [`design/overview.md`](design/overview.md), and
[`rollout.md`](rollout.md), composed with the ready inbox and trace/key-lifecycle
test designs. Publication remains at-least-once; outbox and inbox persistence
stay separate; outbox-only startup remains fail-closed; generic consumer
ordering remains excluded.

## Deterministic controls

- Automatic-disposition policy is table-tested below the database. Durable
  sticky state, lease recovery, operator serialization, ordering-head release,
  cleanup, and receipts are then proved against real PostgreSQL.
- Lost-commit proof controls the commit result independently from committed
  row state and reads only the configured writer-primary authority. A failed,
  canceled, read-only, or unavailable read can never authorize mutation retry.
- NATS unit tests separately control prevalidation, pre-dispatch rejection,
  ambiguity, unknown error, acknowledgement, readiness, terminal return, and
  shutdown. Real JetStream proves only broker-owned acceptance and W3C flow.
- Lifecycle tests synchronize on owned start/ready/terminal/drain/join/shutdown
  events, using `testing/synctest` for time horizons. Sleeps are outer failure
  diagnostics only.
- SQL/migration sources remain canonical and generated outputs are drift proof,
  not hand-edited evidence.
- Commands naming new tests are post-implementation commands. A current
  `no tests to run` result is a proof gap, not a pass; the named scenario and
  oracle must exist before its command can be accepted.

unfinished event, or serializes generic consumer handling.
