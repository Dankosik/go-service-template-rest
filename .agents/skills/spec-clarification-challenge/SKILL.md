# Spec Clarification Challenge

Must read [Specification](../../../docs/spec-first-workflow/phases/specification.md).
Treat the approval question as a one-way door: test its material consequences,
alternatives, blast radius, exit cost, and reversibility read-only. Return the
recommended option with evidence and reopen condition when agent-owned under
[Decision Ownership](../../../AGENTS.md#decision-ownership); otherwise return
the user-owned options and owner without authoring or approval.
