# Go Verification Before Completion

Use [Implementation / Validation / Closeout](../../../docs/spec-first-workflow/phases/implementation-validation-closeout.md) for completion authority. Load [the reference selector](references/index.md) only when one concrete proof pressure can change the command or conclusion. Map each claim to fresh proof of equal scope and reject stale or narrower evidence. Route unknown root cause to `go-systematic-debugging` and unset rollout criteria to `go-delivery-platform`. Return `verified`, `partially verified`, or `not verified` with commands and the next action; do not repair or invent proof.
