# Planning Session

Must read [Planning](../../../docs/spec-first-workflow/phases/planning.md); it owns ledger authoring, readiness, and the implementation-start boundary. Produce the smallest owned ledger whose next task or real parallel wave is executable and provable. Apply root self-review; use independent Readiness Review only when its shared trigger applies. Carry dispositioned later concerns forward, and seek fresh review only after `FAIL` repair or material candidate change. Stop when Planning permits implementation or names the owner to reopen.
