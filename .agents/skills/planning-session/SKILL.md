# Planning Session

Must read [Planning](../../../docs/spec-first-workflow/phases/planning.md); it owns ledger authoring, Readiness Review, repair, and the implementation-start boundary. Drive ledger closure over every accepted obligation, dependency path, proof gap, wave, and readiness finding. Readiness Review becomes available only after authoring meets Planning's bar; each finding is repaired or routed to its upstream owner, and a repaired candidate receives fresh Review. Stop only when Planning's Stop Rule permits implementation or names the owner to reopen.
