# Planning Session

Must read [Planning](../../../docs/spec-first-workflow/phases/planning.md); it owns ledger authoring, review routing, repair, and the implementation-start boundary. Drive ledger closure over every accepted obligation, dependency path, proof gap, wave, and readiness finding. Self-review is the default. Run exactly one independent read-only review only when explicitly requested or when the fixed plan is high-impact, hard to reverse, cross-owner, or weakly falsifiable. Repair findings or route them upstream; obtain fresh review only when that triggered review occurred and a semantic repair changed material. Stop only when Planning's Stop Rule permits implementation or names the owner to reopen.
