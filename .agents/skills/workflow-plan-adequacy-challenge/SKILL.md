# Workflow Plan Adequacy Challenge

Challenge handoff integrity read-only when routing or handoff is high-impact, contested, or explicitly requested; return every anchored gap and its next owner, or an evidence-backed no-gap result. Use [the artifact model](../../../docs/spec-first-workflow/shared/artifact-model.md) rather than restating its method.
