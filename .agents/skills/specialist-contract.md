# Shared Specialist Contract

Select the domain by the absent or changing decision or the violated accepted
contract. Use **Decision** when policy is absent or changing and **Review** when
current code or artifacts must conform to accepted policy. Load one domain
reference by default and another only for an independent pressure.

A Decision returns [Decision Result V1](decision-result-v1.md). A Review uses
current evidence and the shared [Finding
Envelope](../../docs/spec-first-workflow/shared/review-findings-and-convergence.md#finding-envelope).
Missing policy returns to the same domain's Decision branch when available, or
the nearest affected decision owner. Load [specialist
arbitration](specialist-arbitration.md) only for ambiguous domain overlap.

Stay inside the selected domain and return only its judgment, proof, or gap.
