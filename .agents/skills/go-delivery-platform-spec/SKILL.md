# Go Delivery Platform Spec

Load the [shared specialist contract](../specialist-contract.md) for selection, evidence, return, and handoff. Define proportional gates, stable required statuses, local/CI parity, provenance, migration/rollback, and release policy. Load [the reference selector](references/index.md) only when its pressure changes the result, and another reference only for an independent pressure. Escalate service resilience policy to `go-reliability-spec` and trust controls to `go-security-spec`. Return the owned decision or evidence-backed finding, forced consequence, and focused proof; stop rather than inventing another owner’s policy.
