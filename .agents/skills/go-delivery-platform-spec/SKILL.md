# Go Delivery Platform Spec

Load the [shared specialist contract](../specialist-contract.md) for selection, evidence, return, and handoff. Define proportional delivery acceptance: stable required statuses, local/CI parity, provenance, migration/rollback, and release policy. Load [the reference selector](references/index.md) when a concrete pressure changes the decision; load another reference only for an independent pressure. Hand service resilience policy to `go-reliability-spec`, trust controls to `go-security-spec`, and other unresolved policy to its named owner. Return the owned decision or evidence-backed finding, forced consequence, focused proof, and any blocker.
