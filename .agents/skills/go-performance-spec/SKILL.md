# Go Performance Spec

Load the [shared specialist contract](../specialist-contract.md) for selection, evidence, return, and handoff. Define workload, budgets, baseline, bottleneck hypothesis, measurement, capacity, rollout, and rollback. Load [the reference selector](references/index.md) only when its pressure changes the result, and another reference only for an independent pressure. Escalate cache/data semantics to `go-db-cache-spec` and overload policy to `go-reliability-spec`. Return the owned decision or evidence-backed finding, forced consequence, and focused proof; stop rather than inventing another owner’s policy.
