# Spec First Brainstorming

Build the problem frame from the chosen direction: behavior delta, scope, constraints, risks, owners, and proof for specification, while routing unresolved policy to its owner. Use [the workflow router](../../../docs/spec-first-workflow.md) and load [the reference selector](references/index.md) only when one concrete framing pressure can change the behavior delta, scope, assumptions, challenge routing, or readiness. Return a readiness decision, required/recommended/skippable challenge routing when relevant, and the named next owner.
