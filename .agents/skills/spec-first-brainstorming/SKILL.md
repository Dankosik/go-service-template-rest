# Spec First Brainstorming

Build the frame by reconstructing every behavior delta, scope boundary, constraint, assumption, risk, owner, and proof expectation from the chosen direction, current contracts, and affected user/operator surfaces. Ask only questions that sharpen those units, then disposition each as represented, preserved, open decision, external input, or blocker so Specification need not guess meaning. Use [the workflow router](../../../docs/spec-first-workflow.md) and load [the reference selector](references/index.md) only when one concrete pressure can change the frame, challenge routing, or readiness. Complete with the frame, readiness and challenge-routing decisions, and the named next owner.
