# Spec First Brainstorming

Build the frame by reconstructing every behavior delta, scope boundary, constraint, assumption, risk, owner, and proof expectation from the chosen direction, current contracts, and affected user/operator surfaces. Decide every technical unit yourself from current evidence and keep only a question that survives [Decision Ownership](../../../AGENTS.md#decision-ownership), then disposition each unit as represented, preserved, decided default, open decision, external input, or blocker so Specification need not guess meaning. Use [the workflow router](../../../docs/spec-first-workflow.md) and load [the reference selector](references/index.md) only when one concrete pressure can change the frame, challenge routing, or readiness. Complete with the frame, readiness and challenge-routing decisions, and the named next owner.
