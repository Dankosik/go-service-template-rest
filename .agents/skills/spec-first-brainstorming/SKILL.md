# Spec First Brainstorming

Frame a chosen direction into behavior delta, scope, constraints, risks, owners, and proof for specification; do not settle unresolved policy. Use [the workflow router](../../../docs/spec-first-workflow.md) and load [the reference selector](references/index.md) only when its pressure changes the frame. Return a readiness decision, required/recommended/skippable challenge routing when relevant, and the named next owner.
