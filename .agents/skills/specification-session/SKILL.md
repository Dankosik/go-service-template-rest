# Specification Session

Must read [Specification](../../../docs/spec-first-workflow/phases/specification.md); it owns the Decision Bar, review routing, repair, and stop rule. Drive spec closure over every affected behavior decision and anchored finding. Self-review is the default. Run exactly one independent read-only review only when explicitly requested or when the fixed decision is high-impact, hard to reverse, cross-owner, or weakly falsifiable. Repair findings or route them upstream; obtain fresh review only when that triggered review occurred and a semantic repair changed material. Stop only when Specification permits design or planning, or names the owner to reopen.
