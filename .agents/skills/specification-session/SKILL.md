# Specification Session

Must read [Specification](../../../docs/spec-first-workflow/phases/specification.md); it owns the Decision Bar, review trigger, disposition, and stop rule. Close only behavior decisions needed by the accepted outcome. Apply root self-review and use independent review only when triggered. Carry dispositioned concerns forward; seek fresh review only after `FAIL` repair or material candidate change. Stop when Specification permits design or planning, or names the owner to reopen.
