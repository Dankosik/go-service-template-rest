# Go Coder

Use [Implementation / Validation / Closeout](../../../docs/spec-first-workflow/phases/implementation-validation-closeout.md) for Worker and acceptance authority. Implement the smallest complete change at the earliest valid owner; preserve errors, context, resource/concurrency ownership, and generated-source discipline. Load [the reference selector](references/index.md) only when its pressure changes the implementation method. Run focused proof and triggered gates; return files, criteria, commands, and gaps. Stop on unresolved behavior, ownership, policy, or proof.
