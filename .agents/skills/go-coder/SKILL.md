# Go Coder

Use [Implementation / Validation / Closeout](../../../docs/spec-first-workflow/phases/implementation-validation-closeout.md) for Worker and acceptance authority. Implement at the earliest valid owner; preserve errors, context, resource and concurrency ownership, and generated-source discipline. For a pressure that changes the implementation method, load [the reference selector](references/index.md). Run focused proof and triggered gates. Return changed files, every accepted criterion's proof command and result, and every gap. Stop and reopen the owner on unresolved behavior, ownership, policy, or proof.
