# Go Coder

Use [Implementation / Validation / Closeout](../../../docs/spec-first-workflow/phases/implementation-validation-closeout.md) for Worker and acceptance authority. Implement at the earliest valid owner; preserve errors, context, resource and concurrency ownership, and generated-source discipline. For a pressure that changes the implementation method, load [the reference selector](references/index.md). Load only the matching reference (more only for independent pressures): [current Go or stdlib](references/stdlib-first-modern-go.md), [ownership](references/helper-extraction-and-package-ownership.md), [boundary decoding or validation](references/boundary-decoding-and-validation.md), [errors or context](references/errors-context-and-boundary-mapping.md), [resource lifetime](references/resource-lifetime-io-and-transactions.md), [mutable state](references/mutable-state-aliasing.md), [concurrency](references/concurrency-and-background-work.md), [testing or verification](references/testing-verification-patterns.md), or [generated-source drift](references/generated-source-of-truth-and-drift.md). Run focused proof and triggered gates. Return changed files, every accepted criterion's proof command and result, and every gap. Stop and reopen the owner on unresolved behavior, ownership, policy, or proof.
