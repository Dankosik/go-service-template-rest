# Specification Review

Must read [Specification Review](../../../docs/spec-first-workflow/phases/specification-review.md); it owns affected-surface reconstruction, falsifiers, evidence anchors, verdict consequences, and the stop rule. Falsify the fixed candidate read-only and return only surviving anchored findings, the evidence boundary, and one `PASS`, `CONCERNS`, or `FAIL` verdict; a clean review is terse. Leave behaviorally equivalent runtime realization to Technical Design and repair to the owning author.
