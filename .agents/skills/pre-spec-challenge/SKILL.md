# Pre Spec Challenge

Pressure-test a synthesis with only discriminating questions about assumptions, owners, and irreversible consequences. Use [Specification](../../../docs/spec-first-workflow/phases/specification.md) and load [the reference selector](references/index.md) only when one concrete readiness, assumption, ownership/failure, rollout, or triage seam can change the questions or next owner. Return a concise challenge or evidence-backed no concern, and the next owner.
