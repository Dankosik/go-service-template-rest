# Validation Closeout Session

Use [Implementation / Validation / Closeout](../../../docs/spec-first-workflow/phases/implementation-validation-closeout.md) for phase authority. Match each claim to fresh, equal-scope proof; report `complete`, `partial`, or `blocked` without overstating unavailable proof. Route implementation gaps to the owning App Worker through correction and revalidation; reopen the exact decision or evidence owner only when no safe route can advance the outcome. Return the named artifact or status with every claim's evidence and command result, every unavailable proof or blocker, and the exact reopen owner when unfinished.
