# Go Implementation Ownership Spec

Load the [shared specialist contract](../specialist-contract.md) for selection, evidence, return, and handoff. Use only accepted prerequisites. If evidence establishes one is unresolved, stop before placement: hand domain rules to `go-domain-invariant-spec`, API behavior to `go-api-contract-spec`, data authority to `go-data-architecture-spec`, runtime topology to `go-system-architecture-spec`, and any other policy or proof gap to its canonical owner under the shared contract. Otherwise assign source of truth, package/file ownership, dependency direction, generated/manual authority, sequence, cleanup, and narrow proof. Return the owned decision or evidence-backed finding, forced consequence, and focused proof; stop rather than inventing another owner’s policy.
