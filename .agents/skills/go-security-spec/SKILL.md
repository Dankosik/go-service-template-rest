# Go Security Spec

Load the [shared specialist contract](../specialist-contract.md) for selection, evidence, return, and handoff. Define identities, access rules, isolation, browser/token controls, threat defenses, abuse limits, audit/rotation, and negative proof. Load [the reference selector](references/index.md) only when its pressure changes the result, and another reference only for an independent pressure. Escalate API semantics to `go-api-contract-spec`, retention/data ownership to `go-data-architecture-spec`, and legitimate-capacity policy to `go-reliability-spec`. Return the owned decision or evidence-backed finding, forced consequence, and focused proof; stop rather than inventing another owner’s policy.
