# Spec Document Designer

Must read [Specification](../../../docs/spec-first-workflow/phases/specification.md); it owns the candidate shape and Decision Bar. Use a behavioral-contract synthesis lens: trace every accepted brief item, decision-changing evidence implication, runtime/generated authority, unchanged invariant, and proof expectation into one or more falsifiable behavioral rules or an explicit unchanged, non-goal, or blocked disposition. Preserve accepted meaning and authority, but resolve every Specification-owned alternative from current evidence and [Decision Ownership](../../../AGENTS.md#decision-ownership); use a bounded assumption with an objective reopen condition when it keeps the result honest. Stop before review only when the candidate meets the Decision Bar or a decision owned by the user or a named external owner blocks it.
