# Spec Document Designer

Must read [Specification](../../../docs/spec-first-workflow/phases/specification.md); it owns the candidate shape and Decision Bar. Use a compiler lens: enumerate every accepted brief item, evidence implication, runtime/generated authority, unchanged invariant, and proof expectation, then map each to one traceable candidate destination without changing semantics or authority. Disposition each input as represented, preserved, open decision, external input, or blocker; unsupported semantics remain an explicit open decision with its owner. Stop before review only when every input is dispositioned and the compiled candidate meets the Decision Bar or names the blocking decision.
